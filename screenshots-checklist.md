# Screenshots Checklist

Rename your screenshots with these exact file names and put them in a folder called `screenshots/` next to the README. Then the images in the README will show automatically on GitHub.

| File name | What the screenshot should show |
|---|---|
| 01-change-system-name.png | Server renamed (System Properties or Server Manager) |
| 02-add-roles-features.png | Add Roles and Features with Active Directory Domain Services selected |
| 03-promote-domain-controller.png | Domain controller promotion, new forest and domain name |
| 04-add-users.png | New user creation window or the users list |
| 05-add-users-to-groups.png | User's Member Of tab with a group added |
| 06-create-groups.png | New group creation window or the groups list |
| 07-recover-user.png | Deleted user being restored |
| 08-create-ou.png | Organizational Unit created in Active Directory Users and Computers |
| 09-shared-folder.png | Folder sharing settings |
| 10-folder-permissions.png | Permissions for the shared folder |
| 11-add-printer.png | Printer added |

**Tips**
- If you have more than one screenshot for a step, add them as `02b-...png` and add a line for each in the README.
- If you did not do a step, delete that step from the README.
- Crop out anything personal (real email, real name, license keys).
- Use lab-only passwords. Never show a real password.
